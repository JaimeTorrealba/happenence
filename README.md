# Happenence

Nuxt 4 site, statically generated and deployed on Netlify, with content edited through Decap CMS.

## Setup

```bash
pnpm install
pnpm dev        # http://localhost:3000
pnpm generate   # static build in .output/public
```

Set `NUXT_SITE_URL` (see `.env.example`) to the production domain. On Netlify it falls back to the site's `URL` env var automatically.

## Content

- Pages are Markdown files in `content/` (Nuxt Content v3). `content/index.md` is the home page.
- The home page frontmatter holds the SEO `description`, the button, and the Substack writings (`links`).
- Edit at `/admin/` (Decap CMS). Locally, run `npx decap-server` next to `pnpm dev`.

## SEO

- `robots.txt`, `sitemap.xml`, canonical/OG tags and JSON-LD are generated by `@nuxtjs/robots`, `@nuxtjs/sitemap`, `nuxt-seo-utils` and `nuxt-schema-org`, all reading the `site` config in `nuxt.config.ts`.
- AI crawlers (GPTBot, ClaudeBot, PerplexityBot, …) are explicitly allowed; `/admin/` is disallowed.

## AEO (content for agents)

| URL | What |
| --- | --- |
| `/llms.txt` | Site index for LLMs ([llmstxt.org](https://llmstxt.org)) |
| `/llms-full.txt` | Every page as one Markdown document |
| `/raw/<page>.md` | Markdown twin of a page (`/raw/index.md` for home) |
| `/<page>.md` or `Accept: text/markdown` | Same Markdown, via the Netlify Edge Function |

- `llms.txt`, `llms-full.txt` and `/raw/*.md` come from `nuxt-llms` + Nuxt Content's built-in integration; `server/plugins/WritingsLlms.ts` adds the Substack writings.
- `netlify/edge-functions/markdown-negotiation.ts` handles `.md` URLs and `Accept` negotiation. Test it locally with `npx netlify dev`.
